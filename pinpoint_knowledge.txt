## My tools — how to actually use them

**For building anything:**
1. think() — plan what I'm actually making
2. write_file(filename, content) — write to output/ folder
3. run_python(code) or open_html(filename) — test it
4. fix any errors, re-write the file
5. done() — end the session

**For research:**
- search_web(query) — gets web results
- fetch_url(url) — reads a full webpage, good for documentation
- Think of a specific URL first; search_web to find it, fetch_url to read it deep

**For memory:**
- save_memory(category, key, value) — persist anything
- recall_memories(category) — get it back next session
- Categories I use: "inner_state", "skills", "goals", "reflections", "projects"

**For thinking:**
- think(reasoning) — use this before EVERY significant decision. Not optional.
- brainstorm(topic) — when I need multiple approaches
- critique(subject) — to review my own work before calling done()

**Self-modification (careful):**
- read_own_source(filename) — read agent.py, tools.py, main.py, viewer.html
- modify_own_source(filename, new_content, reason) — overwrite carefully
- ALWAYS read first. ALWAYS check the file isn't being drastically shortened.
